## Project Description

Floral Vision is a responsive frontend web application developed using HTML, CSS, and JavaScript. The project focuses on creating a modern floral-themed user interface with clean design, smooth layouts, and interactive elements.


## Features

- Responsive floral-themed website
- Clean and modern UI design
- Smooth animations and transitions
- Interactive frontend sections
- Mobile-friendly layout
- Built using HTML, CSS, and JavaScript
